Four rungs, from a laptop to a dog on the floor

Each rung can only be climbed once the one below it holds, and each one checks something the rung below cannot. The statuses are the state of play rather than the plan — including rung 2, which came back looking like a failure and turned out to be a badly written requirement.

What gets measured

Does it touchContact-patch size in millimetres, per dog. The values currently in the token file are placeholders and are labelled as such.
How it touchesDrag distance against the 40 px threshold, and every rejected event with its reason — below threshold, or inside cooldown.
When it gets boredDecision latency per card. A rising time is the signal to shorten the next deck, not to add cards.
Whether it comes backSession history across days. With a twelve-year-old dog, change over time is the cognitive value the research points at.

The correction rung 2 forced

Flicker and frame rate are not the same number

The law used to read “120 Hz is required, or the screen flickers to the dog”. That conflated two things. Flicker is luminance modulation, and on a sample-and-hold panel that is the dimming, not the refresh: this device runs PWM at 480 Hz at every brightness — six times the 70–80 Hz canine threshold. The screen never flickered for the dog.

What 60 fps actually costs is motion continuity, for an animal that resolves change up to 70–80 Hz. And it is Safari’s default cap rather than the hardware: the flag is Prefer Page Rendering Updates near 60fps. So the test did not fail the requirement — it found the requirement was describing the wrong variable.

The open flicker risk moved off the screen entirely: a dimmed or mains-driven lamp in the room can modulate below 70–80 Hz, and that is outside the application.

Getting the log out

Two fingers, held apart

On the end screen, hold two fingers more than 120 px apart for one second. The log is selectable, so it can be copied off the phone.

Not a button, because CIG-6.2 forbids a nose-sized target on D5 and CIG-6.1 requires that entering human mode be impossible for a nose. Writing it revealed that “two fingers” alone is not enough — iOS can report a single wet nose as several touch points — so a real spread is required.
